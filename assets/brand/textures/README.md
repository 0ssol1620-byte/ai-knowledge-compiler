# Material texture system

The production texture set is deterministic CSS in `structara.css`:

1. warm paper fiber
2. technical tracing
3. subtle ink bleed
4. fine dot/dither
5. coordinate grain
6. scan-line microtexture
7. emboss field
8. neutral studio noise

Each texture is first-party, seam-safe, color-token driven, and constrained to
approximately 1–3% visible opacity. Warm paper fiber is used on the marketing
canvas; neutral studio noise and scan-line microtexture support the security
chapter. The others remain available for route-specific use without adding
raster downloads.
