# Structural glyph system

The first-party SVG sprite at
`apps/web/public/brand/tavonel-glyphs.svg` contains all 18 approved glyphs:
Page, Block, Table, Evidence, Verified, Note, Node, Branch, Formula, Figure,
Relation, Perspective, Timeline, Package, API, Policy, Audit, and Review.

The sprite uses a 24-unit optical grid, round line caps, and `currentColor`.
Functional navigation continues to use the existing icon library; these glyphs
are reserved for the TAVONEL transformation language.
