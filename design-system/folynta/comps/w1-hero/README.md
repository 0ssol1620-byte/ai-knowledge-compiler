# W1 · Hero 정적 시안 — 오너 결정 요청

설계도 §12.2 · §25.1. **여기서 멈춘다.** 아래 3건이 결정되어 `decision.md` 에
기록되기 전까지 W2 는 착수하지 않는다.

재생성 — dev 서버를 띄우고 `/design/hero?variant=<v>&copy=<c>` 를 캡처한다.
`variant` = `frame` · `overlap` · `fullbleed`, `copy` = `d1` · `d2` · `d3`.

---

## 결정 1 · Hero 구성 (§12.2 3안)

컨셉(대응면)은 고정이다. 변주만 비교한다.

| | 파일 | 설명 |
| --- | --- | --- |
| **A · Frame** | `frame-d1-1440.png` · `frame-d1-390.png` | 하나의 액자 안에 좌우 대응. 설계도 권장안 |
| **B · Overlap** | `overlap-d1-1440.png` · `overlap-d1-390.png` | 지식면이 원문면 위로 12% 겹쳐 뜬다 |
| **C · Full-bleed verso** | `fullbleed-d1-1440.png` · `fullbleed-d1-390.png` | 원문면이 화면 우측 끝까지 잘려 나간다 |

**세 안의 차이는 이것뿐이다.** 카피·데이터·좌표·타이포는 동일하다.
§25.2 강제 비교 판정은 사람이 한다 — 순위를 매겨 주시면 기록한다.

관찰한 것 (판정이 아니라 관찰이다):

- **A** 는 액자 경계가 명확해 "한 스프레드"로 읽힌다. 390 에서 세로 스택이 가장 자연스럽다.
- **B** 는 지식면이 앞으로 나와 위계가 뚜렷하지만, §6.3 이 허용하는 깊이 중
  `--depth-overlay` 를 써야 성립한다. 카드처럼 보일 위험이 있다.
- **C** 는 원문이 화면 밖으로 이어져 "문서는 더 많다"는 인상을 준다. 다만
  우측 잘림 때문에 1920 이상에서 여백 처리를 따로 정해야 한다.

## 결정 2 · Hero 카피 (§3.3 3방향)

시안은 **D1 로만** 캡처했다. §25.1 은 카피를 블라인드 테스트로 정하라고 하므로,
같은 레이아웃에 세 카피를 얹어 비교하는 것이 옳다. 세 방향 모두 §25.3 의
10단어 상한을 지킨다.

```
D1  근거 우선 [설계도 권장]   Every output returns / to its source.            (6단어)
D2  보류 우선, 더 공격적      Nothing enters your / knowledge unverified.      (5단어)
D3  기존 유지                Scattered documents, / one verified knowledge base. (6단어)
```

`?copy=d2` · `?copy=d3` 로 즉시 확인할 수 있다. 선택하신 안으로 다시 캡처해
같이 기록하겠다.

D3 은 설계도 스스로 "클리셰 리스크"라고 적어 뒀다 — 열세면 즉시 폐기 대상이다.

## 결정 3 · 액센트 색상각 (§6.2)

`tokens.css` 는 현재 잠정값 `oklch(48% 0.20 265)` 을 쓴다. §6.2 는 이 값이
Linear `#5e6ad2` · Stripe `#635BFF` 와 같은 인디고 계열이라 **벤치마크 3곳 중
2곳과 겹친다**고 지적하고, 250–260° 로 좁힐 것을 요구한다.

시안은 잠정값 그대로 캡처했다. 색상각은 세 구성안 어디서도 달라지지 않으므로
구성 결정과 독립적으로 정할 수 있다. 정해 주시면 토큰의 잠정 주석을 걷어낸다.

## 시안이 담고 있는 것

- 좌측면은 **저장된 bbox1000 좌표대로 블록을 배치한** 페이지다. 흐름 배치가
  아니다 — 그래야 "Table 3" 하이라이트가 실제로 표 위에 놓인다.
- 스레드는 그 좌표에서 계산된다. 좌표가 없는 앵커는 선을 그리지 않는다 (§4.4).
- 390 세로 스택에서는 스레드를 **그리지 않는다.** 기하가 가로 배치 기준이라
  세로에서는 엉뚱한 위치에 닿는다. 텍스트 등가물은 유지된다.
- 수치는 전부 동결 fixture(`demo-data.ts`)에서 온다. 지어낸 값이 없다.

## 시안이 담고 있지 않은 것

- **동작하는 드롭존.** §12.2 의 상태 ②③ 은 W2 다. CTA 는 `<span>` 으로 두어
  §14.3 의 죽은 컨트롤을 만들지 않았다.
- **실제 PDF 렌더.** 좌측면은 페이지 facsimile 이고 "not an actual source"
  라고 명시한다. PDF.js 는 W4 에서 G-E 좌표 계약과 함께 들어온다.
- 모션. §12.2 의 5구간 시퀀스는 승인된 1안에 대해 W2 에서 구현한다.
