# 참조 이미지 판독 기록

## 원본 정보

- 크기: 1080 × 4000px
- 비율: 27:100
- 판독 방식: 세로 방향 5개 타일, 위에서 아래 순서

## 확인 결과

| 타일 | 원본 Y 구간 | 확인된 내용 |
| --- | --- | --- |
| 001 | 0–810px | 단일 올리브-세이지 그린 색면만 존재하며, 콘텐츠·경계·텍스트·질감이 보이지 않음 |
| 002 | 798–1608px | 첫 타일과 동일한 단일 색면이 겹침 구간을 포함해 끊김 없이 이어짐 |
| 003 | 1595–2405px | 중앙 구간에도 예외 없이 동일한 색면만 존재함 |
| 004 | 2392–3202px | 하단 전 구간에도 콘텐츠 또는 명도 차이 없이 동일한 색면이 지속됨 |
| 005 | 3190–4000px | 화면 최하단까지 단일 색면이 유지되며, 마지막 경계에도 별도의 요소가 없음 |

> 화면 색상은 기준 이미지에서 균일하게 보이며, 현재 구현 토큰 `#4D5D3F`를 사용한다. 5개 타일 모두를 순서대로 확인했으며, 겹침 영역과 마지막 경계에 시각적 변화가 없음을 검증했다.

## 구현 검증

- 1080px 폭의 전체 페이지 캡처에서 기준 이미지와 동일하게 콘텐츠·경계·타이포그래피·그림자 없이 단일 올리브-세이지 색면만 렌더링됨.
- 구현 페이지는 최소 4000px 높이를 사용해 기준 이미지의 긴 세로형 화면을 재현함.
