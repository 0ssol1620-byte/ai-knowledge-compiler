# TAVONEL 브랜드 차별화 방향

TAVONEL은 단순한 기업 검색이나 요약 도구가 아니라, **원문 페이지에서 구조·근거·재사용 가능한 지식으로 이어지는 검증 경로를 보여주는 Knowledge Compiler**로 포지셔닝한다. 경쟁 제품이 주로 연결, 요약, 개인화, 대화형 분석 또는 그래프 생성을 강조하는 사이, TAVONEL은 결과가 어디에서 왔는지 사람이 직접 확인할 수 있는 **Proof Lens**를 브랜드의 주된 경험으로 삼는다.

| 경쟁 환경에서 흔한 가치 | TAVONEL의 차별화 경험 |
| --- | --- |
| 연결된 데이터·즉시 답변 | 답변의 **원문 위치와 구조적 근거**를 함께 표시 |
| 다수 소스·개인화된 맥락 | 출처 문서에서 **검증 가능한 지식 패키지**까지의 흐름 |
| AI 분석·그래프 생성 | 사람의 검토가 가능한 **페이지 → 블록 → 근거 → 관계** 인터페이스 |

브랜드는 따뜻한 종이와 잉크를 기본 표면으로, 변화에는 단일 블루를, 출처와 증거에는 시안을 사용한다. 과장된 AI 비주얼이나 무의미한 수치를 피하고, 실제 공개 DART filing의 원문·표·source line을 사용한다. 이를 통해 TAVONEL은 “더 많은 것을 안다”가 아니라 “어떻게 아는지 보인다”는 차이를 만든다.
