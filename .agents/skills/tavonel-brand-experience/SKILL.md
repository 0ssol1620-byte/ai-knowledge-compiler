# TAVONEL Brand Experience

Read root `AGENTS.md`, the relevant masterplan section,
`TAVONEL_BRAND_DECISIONS.md`, `PAGE_MANIFEST.yml`, and existing route evidence
before changing a TAVONEL surface.

## Invariant

TAVONEL is the Knowledge Compiler for AI.

`Page → Structure → Evidence → Knowledge → Intelligence`

Marketing uses Cinematic Intelligence: editorial asymmetry, one dominant
visual idea, real product proof, and no card-wall page structure. Product uses
Calm Precision: dense but quiet, source-first, obvious state, and minimal
decorative motion.

## Visual rules

- Let warm paper and ink dominate.
- Use brand blue only for meaningful transformation.
- Reserve evidence cyan for provenance and verified linkage.
- Prefer border and spacing to shadow.
- Use real public or labeled sample document content.
- Keep every route complete without 3D.
- Design Korean and English line breaks independently.

## Forbidden patterns

- Purple-blue atmospheric gradients
- Glowing AI brains, chrome spheres, or meaningless particles
- Bento grids as the default page structure
- Every section inside rounded cards
- Excessive glass, pills, shadows, or animation
- Fake progress, logos, quotes, scores, certifications, or security claims
- Confidence-only output that hides source evidence

## Workflow

1. Audit the route and define one message.
2. Record the approved composition.
3. Build semantic static layout and responsive behavior.
4. Add real states and source-linked fixtures.
5. Add only purposeful motion and progressive 3D.
6. Capture 1920, 1440, 1024, and 390 evidence plus reduced motion.
7. Run keyboard, accessibility, console, network, and performance checks.
8. Update the manifest, status, and visual QA report.

See `references/brand-foundation.md`, `references/visual-language.md`,
`references/product-ui.md`, and `references/quality-gates.md` when working in
those areas.
