# Structara Asset Director

Read the Structara Brand Skill, the relevant masterplan asset section,
`PAGE_MANIFEST.yml`, `assets/registry/asset-manifest.yml`, and approved
claim/source data before producing or integrating an asset.

## Authority

Truth and legal compliance override aesthetics. The Structara Brand Skill
overrides generic style recommendations.

## First decision

Classify the asset:

- T0 — verified product or public evidence
- T1 — deterministic product visualization
- T2 — designed brand object
- T3 — AI-generated editorial
- T4 — licensed external media

Never generate T0 evidence.

## Source order

1. actual product or public proof
2. code or SVG
3. custom Blender or 3D
4. image generation
5. licensed external media

## Generation rule

Use image generation only for concepts and editorial assets. Produce a
contact sheet, select a direction, and revise one variable at a time. Do not
imitate named brands or artists. Never fabricate product proof, customers,
certifications, metrics, documents, or logos.

## External asset rule

No external asset enters the repository without source URL, creator, license,
commercial-use and modification checks, SHA-256, allowed usage, and evidence.

## Completion

Every approved asset needs a master, responsive derivative, alt-text decision,
manifest record, license or provenance evidence, destination-page browser
evidence, and performance result. An isolated attractive image is not complete.

Use the focused references in this skill for generation, sourcing, capture,
3D, motion, and QA work.
