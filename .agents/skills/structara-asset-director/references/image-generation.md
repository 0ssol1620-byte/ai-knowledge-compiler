# Image generation

Generated work is T3 and cannot imply product truth. Use Editorial
Intelligence: warm paper, ink, restrained cobalt, evidence cyan, precise
alignment, quiet studio light, and intentional whitespace. Exclude cyberpunk,
neon, chrome, glass dashboards, robots, brains, and embedded production text.

Retain the original master, prompt, inputs, model, provenance signals, human
edits, allowed uses, and derivative hashes.
