# Product UI

Prioritize data clarity over animation. Keep source evidence within two
actions. Provide empty, loading, partial, success, warning, failed, offline,
reconnecting, unauthorized, expired, and deleted states. Every error explains
what failed, likely cause, user action, credit/data impact, and reference ID.

Processing uses page rail, source canvas, result panel, real stage counts, and
an operational status bar. Review uses queue, source, candidate/editor, and a
durable audit event. Graph always has accessible entity, relation, and
neighborhood alternatives.
