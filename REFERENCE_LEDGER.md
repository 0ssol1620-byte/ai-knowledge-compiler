# Reference ledger

## Linear

Take: quiet hierarchy, consistent contextual headers, real workflow in
marketing. Do not take: a dark developer-tool identity.

Applied to: app shell, Processing Studio, project tables.

## Vercel

Take: persistent navigation grammar, high-contrast tokens, responsive
recomposition. Do not take: monochrome developer branding.

Applied to: public header and authenticated shell.

## Reducto and Chunkr

Take: inspectable parsing, source citation, task states, typed output. Do not
take: API-first language for first-time visitors.

Applied to: proof demo, Processing and Review Studios.

## Obsidian and Neo4j Bloom

Take: notes, properties, backlinks, search-first graph perspectives, and proof
inspection. Do not take: showing the entire graph by default.

Applied to: Knowledge and Graph workspaces.

## Figma Config 2026

Take: expressive structural glyphs and controlled human texture. Do not take:
shaders as ambient decoration.

Applied to: page, block, link, node, and branch glyphs.

## Spline

Take: rapid camera prototyping only. Production uses React Three Fiber unless
measured embed performance earns an exception.

Result: no Spline runtime or asset is shipped. The production hero is a
first-party React Three Fiber scene with server-rendered poster continuity,
reduced-motion handling, and WebGL failure recovery.

## Asset System v2.1

Take: actual product/public proof first, deterministic SVG/HTML second,
first-party 3D third, generated editorial only as a controlled optional layer.
Do not take: stock imagery, generated dashboards, decorative paper stills, or
external assets without a concrete missing page question.

Applied to: T0 Product route captures, T1 architecture diagrams, T2 hero,
18-glyph family, six patterns, eight textures, and the asset registry.
