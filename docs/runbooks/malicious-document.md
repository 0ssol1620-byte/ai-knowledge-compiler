# Malicious Document Response

1. Keep the object in quarantine; revoke all grants and stop derivatives.
2. Record hashes, declared/observed media type, scanner versions, parser image,
   archive metadata, and failure codes. Do not attach the payload to a public
   issue.
3. If execution or network access is suspected, isolate the worker, preserve
   runtime evidence, rotate reachable secrets, and declare SEV-0/SEV-1.
4. Search by safe hashes and job IDs for related uploads without exposing
   customer content.
5. Update signatures, limits, sanitizer rules, and a harmless synthetic
   regression fixture. Dangerous samples belong only in the private security
   corpus under controlled access.
6. Reprocess only after a patched sandbox and the security suite pass.
7. Follow the approved abuse, infringement, privacy, and customer-notification
   procedures.
