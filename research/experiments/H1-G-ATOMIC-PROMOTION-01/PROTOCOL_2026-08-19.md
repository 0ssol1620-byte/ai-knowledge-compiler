# H1-G — atomic promotion contract audit

Frozen 2026-08-19 before H1-G audit execution.

## Purpose

Consolidate the live fail-closed world-state promotion and sealed build-receipt contracts into one code-pinned controlled audit. This does not introduce a new promotion algorithm and does not claim external validity.

## Pinned implementation and tests

The seal pins the exact bytes of:

- `packages/cir-python/src/akc_cir/world_state.py`
- `packages/cir-python/src/akc_cir/build_receipt.py`
- `tests/unit/test_world_state.py`
- `tests/unit/test_build_receipt.py`
- this protocol and audit runner.

The run refuses any drift from the seal.

## Required live contract classes

The audit is valid only if the pinned test files contain named tests covering all of the following contract classes:

1. candidate artifact checksum mismatch refuses publish;
2. a refused publish leaves the prior ACTIVE state serving;
3. failed integrity validation refuses publish;
4. an unrun permission check refuses publish;
5. a rejected candidate cannot later be retried into ACTIVE;
6. publishing an unstaged/non-candidate state is refused;
7. selective publish with missing equivalence evidence is refused;
8. selective publish whose full-rebuild equivalence fails is refused;
9. a successful publish emits exactly one world-state event;
10. a refused publish emits no publish event;
11. rollback restores a previously published state and cannot publish an unvalidated candidate;
12. a receipt from the prior world state is refused;
13. a receipt for another artifact is refused;
14. correct receipt plus wrong current bytes is refused;
15. changed live input fingerprint is refused;
16. editing any sealed receipt field breaks the seal;
17. an untracked builder is refused by default rather than falsely claimed detected;
18. the explicit permissive untracked path is downgraded and never promotable to HIGH_INTEGRITY;
19. changing an untracked receipt's tracked flag breaks the seal.

## Endpoint

Run exactly:

`python -m pytest -q tests/unit/test_world_state.py tests/unit/test_build_receipt.py`

using the repository `.venv` interpreter under the sealed bytes.

Primary audit endpoint: process exit code 0 **and** all required named contract tests are present in the sealed test files.

The receipt records test count from pytest output, pinned file hashes, interpreter/platform information, and the required-contract checklist.

## Evidence class / boundary

Evidence class: `CONTROLLED_IMPLEMENTATION_CONTRACT_AUDIT`.

Allowed wording on pass:

> Under the pinned in-memory world-state and build-receipt implementations, the controlled contract audit passes the enumerated fail-closed publication, rollback, receipt-binding, and untracked-downgrade cases.

Required limitation:

> This is implementation/unit-contract evidence. It does not prove distributed database atomicity under arbitrary process crashes, external storage faults, network partitions, or complete capture of every input an unconstrained builder may consume.

Forbidden:

- “atomic promotion is proven under all production failures”;
- “the build receipt proves every builder input was captured”;
- treating a permissive untracked builder as HIGH_INTEGRITY;
- using this audit as external real-corpus evidence.
