# H1-D Governance / Temporal / Lineage controlled validation — frozen before execution

`PATENT_FILING = NOT FILED`. `PAPER_SUBMISSION = NOT SUBMITTED`.

Purpose: close evidence gaps that previously had implementation/unit tests but no
independent experiment receipt. This experiment is deliberately **controlled**;
it validates mechanism semantics and reason-path correctness, not real-world
frequency or automatic extraction quality. No LLM/GPU is useful here.

## 1. Authority / applicability / conflict

Run **500 deterministic cases per cell**, seed `2026081908`. Gold outcomes are
constructed independently from the resolver output.

Cells:
1. inapplicable higher-authority claim vs applicable lower-authority claim;
2. narrower scope vs broader scope at equal authority;
3. regulatory vs contractual at equal scope;
4. active vs withdrawn at equal otherwise;
5. equal-precedence divergent values => `CONFLICTED`, no selected claim, review required;
6. evidence-backed explicit override beats otherwise-higher authority;
7. same override condition without explicit evidence does **not** fire;
8. permission-hidden stronger claim is excluded and its claim id is absent from the user-facing record;
9. temporal validity window excludes a higher-ranked claim outside its interval;
10. no applicable claim => `NO_CANDIDATE`.

Primary: exact expected status/winner/review semantics in all 5,000 cases; privacy
cell additionally requires zero hidden-id leakage.

## 2. Bi-temporal integrity / contradiction / replay

Run **500 deterministic cases per cell**, same seed but independently derived RNG.

Cells:
1. backdated fact recorded later: valid-time can include it while a prior
   known/system-time query excludes it;
2. superseded fact is known before retraction and absent after `superseded_at`;
3. overlapping validity windows with different values produce a contradiction;
4. non-overlapping differing values do not produce a contradiction;
5. unknown validity is excluded by default and included only under explicit
   `INCLUDE_UNKNOWN` policy with audit annotation;
6. `replay_context(at=t)` requires both reality-valid and system-known at `t`.

Primary: exact gold set/status semantics in all 3,000 cases. This does **not**
claim that TAVONEL automatically extracts valid-time windows from prose.

## 3. Semantic lineage / impact / agent consumption

Run **500 deterministic cases per cell**. Each case uses fresh opaque node ids and
decoy branches; gold affected sets are generated from the case topology, not from
`impact_of` output.

Cells:
1. semantic evidence -> claim -> ontology -> retrieval -> answer-context -> exact
   prior consumption receipt; expect all and only the gold chain plus receipt;
2. unrelated decoy consumption must remain unflagged;
3. evidence **locator relocation** on a LOCATOR-only branch updates only locator
   artifacts and must not propagate into semantic derived knowledge;
4. 64-hop semantic chain reaches every downstream node; final reason path has
   depth 64 and names the seed/final endpoint;
5. temporal channel change reaches temporal consumers but not semantic-only decoy;
6. `provenance_of(final)` reconstructs all and only the gold upstream chain.

Metrics: affected-set precision/recall, stale-consumption precision/recall,
reason-path exactness, orphan/missed downstream count, false-impact count.
Primary criterion is **1.0 precision and 1.0 recall in every cell with zero
reason-path failures**.

## 4. Frozen reporting rules

- A failed cell is preserved; no aggregate average may hide it.
- If the harness is demonstrably inconsistent with this protocol, preserve the
  attempt, correct only the harness, and rerun the same frozen counts/seed.
- If production/core semantics are wrong, add a regression test and repair on
  development data before any new independent holdout; do not relabel the gold.
- GPU cost `$0.00`.
- Claims are limited to controlled mechanism correctness; external/generalization
  evidence remains a separate axis.
