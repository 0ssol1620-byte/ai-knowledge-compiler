## 4. Two measurements that changed the freeze, taken before the money ran out

Both are recorded in `receipts/v8-runtime-feasibility-2026-08-20.json`. The pod
that produced them was deleted, so that receipt is the only record.

### 4.1 The reasoning preamble does not finish inside 256 tokens

`W6-V8-RUNTIME-01`. Qwen3.6's default chat template emits a reasoning preamble.
Asked to *"Reply with exactly one word: attested."*, the live runtime was still
inside a numbered "Thinking Process" when it hit the frozen 256-token limit. The
same runtime with `chat_template_kwargs {"enable_thinking": false}` answered a
one-fact excerpt with the bare value `1,450` in **6** completion tokens, and an
excerpt lacking the fact with exactly `INSUFFICIENT_EVIDENCE` in **7**.

`max_tokens = 256` is a founder decision and is not being reinterpreted. Under
that budget, leaving the preamble on would have made **every arm** run out of
tokens mid-reasoning and score as an abstention — the run would have measured the
preamble, not the four representations. The preamble is therefore disabled
**identically for all four arms**, which changes the shared model contract and not
the variable under test, and it is pinned in the freeze.

**Wording boundary:** the result may not be described as measuring Qwen3.6 *with
reasoning enabled*, and the preamble finding is about this checkpoint's default
template under a 256-token budget — not about the model's reasoning ability.

### 4.2 RAW fits, at development scale

The largest before+after pair in `corpus-v7` is 521,344 characters →
**170,106 prompt tokens**, accepted by the runtime at its 262,144-token window and
answered in 24.8 s. So `RAW_GETS_WHOLE_DOCUMENT_BUDGET` is not expected to
overflow at development scale.

**Holdout documents are not known to be the same size.** `RAW_CONTEXT_OVERFLOW`
stays a recorded outcome in the runner, not an assumed impossibility.

### 4.3 A packaging fact, recorded because it cost a pod

`vllm/vllm-openai` declares `ENTRYPOINT ["vllm","serve"]` and ships no sshd, so
nothing can run beside the server on it. Nine attestation fields include a
model-file digest manifest, which cannot be observed without reading the served
files, and **a manifest observed on a different machine is not the identity that
executed**. The runtime is therefore built on an image that permits a shell, and
the attestation records the base image digest *together with* the full installed
package manifest rather than implying that one image digest pins the whole
runtime. That is a weaker claim than a baked image, stated as such.

## 6. Exactly what happens when funds are added

Nothing below requires a decision. The founder decisions of §7 of the master
handoff are already implemented.

1. **Qualify the runtime.** One 1× H200 pod on an image with a shell
   (`runpod/pytorch:1.0.2-cu1281-torch280-ubuntu2404`,
   digest `sha256:0a360022e8de4375af99430f84e8b38951acc397252163a37ceac7204d01be35`),
   install `vllm==0.27.1`, download `Qwen/Qwen3.6-27B` at
   `6a9e13bd6fc8f0983b9b99948120bc37f49c13e9`, serve it at 262,144 tokens, then:

   ```bash
   python research/experiments/H1-W6-SAME-INTELLIGENCE-01/scripts/attest_runtime_v8.py --mode capture-command --image-digest <digest>
   ```

   run that on the pod, and feed the result back:

   ```bash
   python research/experiments/H1-W6-SAME-INTELLIGENCE-01/scripts/attest_runtime_v8.py --mode capture --attestation-file <file> --pod-id <id> --pod-gpu "NVIDIA H200" --pod-cost-per-hour-usd 4.59
   ```

   Every declared file digest must match the hub's for that commit, or the run
   stays `MODEL_RUNTIME_NOT_READY`.

2. **Freeze**, using the attestation and the already-made decisions.
3. **Full suite**, then the pre-holdout gate; every condition must pass.
4. **Open the holdout once**: manifest → acquisition → question set → taint and
   residual gates → baseline validity gates → four arms → endpoint.

20 minutes; the four arms over 200 primary and 150 control questions are

nothing but takes a few hours of wall-clock and does not need the GPU.

minutes on the pod that was reclaimed. Both are recorded.
