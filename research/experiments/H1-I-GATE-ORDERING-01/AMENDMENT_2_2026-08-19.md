# H1-I Amendment 2 — the claim wording outran the result

**Raised on review of the wording adopted after Amendment 1, before that wording
was relied on anywhere.** No new experiment; a static audit of the
implementation, because the question is about the code's structure and a
permutation study cannot answer it.

## The overclaim

The permutation run established exactly one proposition:

> the conjunctive acceptance result is invariant to evaluation order.

The wording adopted for claim B1 element 7 said something stronger — "a sequence
of **mutually independent** checks, each evaluated against the candidate state
rather than another check's output".

**Order-invariance does not entail independence.** A conjunction of coupled
predicates is still commutative. Nothing in 144 evaluations distinguishes
"independent" from "coupled but commutative", so the stronger word was resting
on nothing the experiment produced.

## Static audit

`scripts/audit_check_independence.py`, receipt
`receipts/check-independence-static-audit-2026-08-19.json`.

| question | finding |
|---|---|
| Q1 does a check consume another's output? | No. No check reads `steps` or any value another check produced. |
| Q2 does a check mutate state a later one reads? | No. The gate calls no mutating method on `diff`, `graph` or `plan`; `DependencyGraph.add` is its only mutator and the gate never calls it. |
| Q3 indirect coupling — cache, accumulator, exception? | None found. `impact_of` builds only local structures and does not memoise; `steps` is append-only and read once for control flow; the gate raises and catches nothing. |
| Q4 does short-circuiting change acceptance semantics? | No. `NOT_REACHED` is a distinct outcome from `PASS` and `promotable` requires all-`PASS`, so skipping a check can only withhold a pass, never supply one. |

## The finding that decides it

`promotion_gate.py:317-330`. When no full-rebuild oracle is supplied, check 3
(INTEGRITY) records PASS with the detail *"no full-rebuild oracle; integrity
rests on the input fingerprints checked in the next step"*, and the source
comment states that check 4 "may not be skipped" for exactly that reason.

No value flows from check 4 to check 3. But **check 3's PASS is not
self-supporting in that branch** — its safety argument is discharged by check 4.
That is a real coupling, of the kind that "mutually independent" denies and that
the permutation experiment could never have detected.

## Adopted wording

> a sequence of **candidate-state predicates whose conjunctive acceptance result
> is invariant to evaluation order**

This is what was measured and what the static audit supports. The specification
carries the delegation finding so the coupling is disclosed rather than papered
over.

## Rule reaffirmed

Never put wording in a claim that is stronger than the result behind it. The
permutation experiment was run correctly; the error was in the sentence written
afterwards, which is a distinct failure mode and is recorded as one.
